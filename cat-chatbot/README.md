# Cat Chatbot
 
具有角色設定與對話記憶的終端機 AI 聊天機器人。
 
---
 
## 功能
 
- 在終端機與 AI 進行多輪對話
- AI 扮演「貓笑話大師」，回應一律使用繁體中文
- 對話紀錄自動儲存為 JSON 檔案，重新啟動後仍記得之前的對話內容
- 輸入 `exit` 離開對話
---
 
## 對話記憶原理
 
OpenAI API 本身無狀態，每次呼叫都是全新的。
透過將每次對話存入 JSON 檔案，並在每次呼叫 API 時傳入完整歷史，實現跨次對話的記憶功能。
 
```
使用者輸入
    ↓
存入 JSON（lowdb）
    ↓
把所有歷史對話一起送給 OpenAI
    ↓
AI 回覆
    ↓
把回覆也存入 JSON
    ↓
下次對話仍記得
```
 
---
 
## 執行
 
```bash
node main.js
 
# 輸入問題後按 Enter 送出
# 輸入 exit 離開
```
